# AILU event gallery assets

Add only event images that AILU has permission to use. Use descriptive, lowercase filenames such as `wedding-stage-01.webp` and reference them from `src/content/site.ts` under the matching event category.

Prepare images at 1600 px wide or larger and compress each file to under 400 KB where possible. Use a format supported by Next.js Image. Every image entry needs meaningful alt text; obtain and retain permission before publishing identifiable people.

The gallery is empty until AILU supplies approved images. Empty gallery sections stay hidden.
